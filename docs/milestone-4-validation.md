# Milestone 4 — публичные страницы, доверие и SEO

Проверено локально в Docker Compose 05.11.2026. Production не публиковался; основной домен продолжает обслуживать прежний сайт.

## Что реализовано

- Каталог и шесть страниц решений: теневые, парящие, тканевые потолки, световые линии, магнитные треки, скрытые карнизы. У каждой свои текст, title, description, H1, изображение, FAQ и контекстная заявка. Иллюстрация парящего решения подписана отдельно от реальных фотографий.
- Сотрудничество с дизайнерами и строительными командами; обращение типа partner с сохранением контекста. Контакты: телефон, Telegram, WhatsApp, Instagram, email, адрес, график и ссылка на маршрут.
- Выбор связанных услуг в редакторе проекта. Связанные кейсы выдаются только после публикации. У пентхауса сохранены связи fabric/cornices; объект на Леонова связан со световыми линиями по существующему описанию. Остальные неподтверждённые системы не приписывались объектам.
- Официальные рейтинг 150×50 и iframe отзывов Яндекса, отдельные ссылки чтения/добавления отзыва. Реальная загрузка обоих виджетов проверена в Chromium; оценка поступает от Яндекса, в исходниках её нет. На телефоне компактный блок размещён сразу после первого экрана.
- Уникальные серверные метаданные, canonical без параметров, Open Graph, структурированные данные без выдуманных оценок, человекочитаемая 404. Sitemap включает публичные страницы и опубликованные кейсы с доменом из SITE_URL. Черновики, кабинет, API и документы туда не входят. Local/preview остаются закрытыми от поиска.
- Отдельные политика, согласие и cookie; управление необязательной аналитикой и внешними iframe. При отправке сохраняются редакция, полный текст и SHA-256 согласия. Изменение текста или реквизитов после открытия формы требует обновления формы. Текст принятого согласия доступен сотруднику в карточке заявки.

## Аналитика

Публичный ID `113716679` извлечён из действующего прежнего сайта, а не придуман. В local/preview загрузка Метрики запрещена независимо от клиентского выбора. Production дополнительно требует `ANALYTICS_ENABLED=true` и разрешения посетителя. Названия JavaScript-целей для создания в кабинете Метрики:

| Группа | Цели |
| --- | --- |
| Подтверждённое сохранение | lead_success |
| Вид заявки | lead_consultation, lead_measurement, lead_project, lead_partner, lead_calculator |
| Контакты | phone_click, telegram_click, whatsapp_click, instagram_click, map_click |
| Отзывы | reviews_click, review_write_click |
| Переход к форме услуги | service_request_click |

Переход к форме не считается успешной заявкой. Успех учитывается после ответа о сохранении; повторное событие той же заявки подавляется локально. Идентификатор используется только внутри браузера. Имя, контакт, комментарий, файлы и reference не передаются в параметры целей. Отправляется canonical без query/hash, внешний referrer сокращается до origin. Вебвизор, карта кликов, автоматические внешние ссылки, автоматический первый hit и Tag Manager отключены. При отказе вызывается destruct. Сторонние cookie и ранее переданные сведения этим не удаляются.

## Проверки

```powershell
docker compose build web
docker compose up -d --no-build --wait
docker compose exec -T web python manage.py test --noinput
docker compose exec -T web python manage.py makemigrations --check --dry-run
node scripts/test-calculator-model.mjs
playwright-cli -s=vlico-m4 run-code --filename=scripts/test-public-site.js
playwright-cli -s=vlico-m4 run-code --filename=scripts/test-calculator-live-price.js
playwright-cli -s=vlico-m4 run-code --filename=scripts/test-calculator-errors.js
```

Все 98 серверных тестов проходят. Проверки покрывают маршруты и SEO, выбор/снятие услуг через настоящий кабинет, доступность только опубликованных связанных работ, исходный контекст обращений, сохранение согласия и отклонение старой формы, включая изменение оператора. Браузерная проверка 12 новых страниц выполнена на 320, 390 и 1440 px: один H1, отсутствие переполнения, загрузка изображений, переходы в формы. Метрика и отправка тестовой заявки перехвачены в браузере: проверены разрешение, отказ, ошибка формы без конверсии, успех при медленной загрузке счётчика, дедупликация, отсутствие содержимого формы и остановка счётчика. Тесты не создают обращения в рабочей базе и не отправляют Telegram-уведомления.

Отдельно выполнена регрессия текущего калькулятора: 13 000 → 16 240 → 28 300 → 31 000 → 50 900 ₽, удаление опций, восстановление черновика, устаревший ответ и обновление версии тарифов. Расчёт и визуальный выбор решений сохранены. Реальные виджеты Яндекса проверены отдельно от теста с перехватом аналитики. Ручной просмотр: услуга на desktop/mobile, каталог, главный экран, рейтинг и отзывы. Физическое мобильное устройство не использовалось. Проверка `check --deploy` в локальном HTTP-окружении выводит четыре ожидаемых предупреждения об HTTPS/HSTS и secure-cookie; для local они намеренно не включаются. Проверка production-инфраструктуры относится к следующему этапу.

После очистки Docker перед сборкой было около 28,8 ГБ свободно на C:. Ограничение 15 ГБ — минимальный запас перед тяжёлой сборкой, а не бюджет на заполнение диска. Volumes не удалялись.

## Перед публичным запуском (milestone 5)

1. Заполнить квадратные скобки: оператор, ИНН/регистрация, юридический адрес, обработчики, сроки хранения, ответственный, хостинг и регламент копий. Проверить фактическое размещение баз и файлов и правовые условия передачи в Telegram. Тексты сами по себе не заменяют выполнение этих требований.
2. Получить доступ к серверу и DNS клиента; проверить HTTPS, российское размещение баз при сборе данных граждан РФ, резервные копии и восстановление. Затем включать индексацию только на согласованном production-домене.
3. В аккаунте владельца счётчика создать/проверить перечисленные цели и получение событий с настоящего production. Доступ к кабинету Метрики в этой работе не предоставлялся; наличие ID не подтверждает права на счётчик. Локально реальные hits намеренно не отправлялись.

## Уточнение блока отзывов — 05.11.2026

Блок перенесён на третье место: первый экран → подход → отзывы → проекты. Текст отзывов не копируется, не редактируется и не пересказывается: выводится официальный виджет Яндекса. Его область увеличена до 960 px; в Chromium на ширине 1440, 768, 390 и 320 px целиком помещаются три исходных превью отзывов. Длинные тексты раскрываются средствами самого виджета. Ссылки на все отзывы и непосредственное написание отзыва сохранены; на desktop заголовок и ссылки остаются рядом при прокрутке блока. На малых экранах ширина iframe не опускается ниже поддерживаемых Яндексом 300 px.

Загрузка одной кнопкой означает отдельное разрешение внешних виджетов, с пояснением передачи технических сведений. Аналитика этим действием не включается. Отказ в настройках удаляет iframe и возвращает кнопку загрузки. Тест `scripts/test-reviews-browser.js` проверяет эти сценарии, настоящий источник отзывов, видимость трёх превью, ссылки и обе страницы с виджетом. Пройдены 18 серверных тестов затронутых публичных страниц/основы и общий браузерный сценарий `scripts/test-public-site.js`; ошибок JavaScript и горизонтального переполнения нет. Внешний вид просмотрен на desktop и телефоне в эмуляции браузера.

# Milestone 2: проверка 04.11.2026

## Результат

Реализован кастомный кабинет, серверная авторизация редактора, черновики и предпросмотр, публикация/снятие, архив/восстановление. Фотографии загружаются группой, оптимизируются, поддерживают обложку, порядок, подписи и раздел результата/монтажа. Добавлены каталог, страницы кейсов, динамические избранные работы на главной и sitemap опубликованных проектов.

В локальной БД подготовлены восемь черновиков и 14 фотографий. Это не утверждение о восьми разных завершённых заказах: три визуальные группы требуют привязки к объектам, остальные записи основаны на клиентских текстах/подписях. Недостающие поля отмечены подсказками и внутренними заметками. Ни один клиентский черновик автоматически не опубликован. Исходники не изменены.

## Выполненные проверки

- Сборка финального Docker image, миграции, collectstatic и запуск --wait: оба сервиса healthy.
- Django check: без ошибок; makemigrations --check --dry-run: без изменений; 21 серверный тест: OK.
- Тесты покрывают права гостя и обычного пользователя, CSRF/POST, закрытые черновики и media, публикацию/снятие на всех публичных поверхностях и в sitemap, обязательную обложку, архив/восстановление, обработку изображений, неверный формат и лимиты, смену обложки и порядка, подписи, подтверждение удаления, запрет удаления последнего фото опубликованного проекта, чужой media ID, устаревшую вкладку, логин/выход, лимит попыток и HTML escaping.
- Playwright CLI: реальный вход редактора, создание служебного проекта, загрузка двух фото, обложка, перемещение, подписи, предпросмотр, открытие галереи, ArrowRight/Escape, публикация, sitemap, снятие, архив, восстановление, удаление фото. Первичный сбой sitemap исправлен регистрацией django.contrib.sitemaps; добавлена регрессионная проверка.
- Проверены desktop и mobile скриншоты кабинета и кейса. Устранена лишняя высота изображений, вызванная HTML height без CSS height:auto. Подсказки предпросмотра не попадают на публичные страницы.
- Ширины 320, 390 и 1280: каталог и кабинет без горизонтального переполнения. Галерея имеет нативный modal dialog, фокус, Escape, кнопки и touch-свайп; без JS ссылки открывают фотографии.
- Проверено сохранение количества проектов/фото и SHA-256 всех WebP после пересборки и пересоздания обоих контейнеров. Служебный проект и тестовые файлы удалены, клиентские черновики сохранены. Повторный seed не создаёт дубликаты и не перезаписывает редакторские изменения.
- Механический Impeccable detector пройден; семантические цвета кабинета документированы в DESIGN.md. Active-tab underline является индикатором состояния, не декоративной карточкой. У интерфейса кабинета нет оркестрованных анимаций.
- Для Gunicorn создан доступный home пользователя и выбран gthread для работы с браузерными соединениями; финальный запуск не содержит ошибок control socket.

## Границы

Формы главной пока демонстрационные, заявки и Telegram не отправляются. Калькулятор и аналитика следуют в следующих milestone. Заполнение портфолио до 10–15 подтверждённых объектов требует уточнения фотографий. Preview/local закрыты от индексации, production не переключался. Доступ редактора создан только локально; секреты остаются в игнорируемых локальных файлах.

# Проверка калькулятора — 5 ноября 2026

Проверены все восемь шагов, условные поля, восстановление ответов, серверный расчёт, изображения и форма заявки на главной и `/calculator/`.

## Исправлено

- Ввод `1e309` в размеры создавал `NaN` в SVG. Визуализация теперь принимает только конечные размеры в допустимых пределах.
- Повреждённый черновик мог восстановить одновременно конкретное освещение и «нет / не знаю», дубликаты и некорректные числа. Восстановление проверяет значения и исключительность ответов.
- При обычном POST JavaScript скрывал готовый серверный расчёт. Результат и серверные ошибки теперь восстанавливаются при запуске интерфейса.
- Пустое поле из неуспешного POST могло заменяться старым значением из черновика. Ответы отправленной формы имеют приоритет, включая пустые значения.
- После исправления контакта сохранялись атрибуты ошибки, а после повторной отправки — старые сообщения. Ошибки очищаются с сохранением исходных подсказок доступности.
- Ответ `null` от сервиса отправки мог оставить форму заблокированной. Необъектный ответ теперь показывает ошибку и позволяет повторить отправку.
- Минимальная площадь проверяется уже на шаге размеров с тем же округлением, что на сервере: `0,1 × 0,1` отклоняется, `0,1 × 0,95` принимается как `0,10 м²`. Ограничение длины названия помещения согласовано с сервером.

## Выполненные проверки

- Docker image пересобран, web и delivery запущены и healthy; Django: **84 теста, OK**.
- `node scripts/test-calculator-model.mjs`, синтаксическая проверка изменённых JS и `git diff --check`.
- Playwright: полный путь восьми шагов, сумма **50 900 ₽**, возврат с сохранением ответов; ширины 1440, 1280, 1024, 768, 390 и 320 px без горизонтального переполнения.
- Расчёт без JavaScript с десятичной запятой: **17 720 ₽**; серверный POST с включённым JavaScript: **16 240 ₽**; неизвестная база показывает индивидуальный расчёт.
- Все варианты материала, примыкания, освещения и штор: изображения загружаются, предпросмотр соответствует выбору, Escape закрывает окно и возвращает фокус, ответы сохраняются при возврате; окно не переполняет узкий экран.
- Потеря сети, исправление контакта, ответ `null`, обновление тарифа 409 и успешная повторная отправка проверены перехватом API. Реальные внешние уведомления при браузерных проверках не отправлялись. Запись заявки, идемпотентность и вложения покрыты серверными тестами в отдельной тестовой БД.

Новые регрессионные сценарии: `scripts/test-calculator-audit.js` и дополнения к серверным тестам и `scripts/test-calculator-model.mjs`. Сценарий аудита запускается через `playwright-cli -s=vlico run-code --filename=scripts/test-calculator-audit.js` при работающем локальном сайте.

## Сохранённые настройки

- Для 13 этапов «VLICO | Входящие клиенты» и 10 этапов «VLICO | Партнёры» записаны и перечитаны инструкции входа, следующего действия, перехода и ручного подтверждения внешних фактов. Структура и названия этапов сохранены.
- В `notifyUserIds` трёх этапов указан существующий человеческий профиль Владлена — «Ожидает согласования замера», «Передано менеджеру», «Заинтересован». Получатель проверен повторным чтением. Доставка уведомления этим не подтверждается.
- Для партнёрской воронки добавлено штатное распределение Владлену по аналогии с клиентской. Контрольная партнёрская карточка получила Владлена в `users`.
- Из «Новый контакт» добавлены три диалоговых правила — явный интерес в «Заинтересован», нейтральный ответ в «Ответ», явный отказ в «Отказ / Запрет сообщений». Ранее такие правила были только у поздних этапов. Задержка правил — 1 минута. Это настройка, а не доказательство скорости или фактического срабатывания.
- Инструкции ручной передачи требуют приостановить ИИ в конкретном диалоге при принятии его оператором. Автоматическая приостановка при одном изменении этапа не подтверждена.

Частная копия настроек до изменения сохранена вне Git в `%TEMP%/vlico-funnels-step5-before-38e226f9977f4193970aca4e85aab56c.json`. В ней сохранены воронки, этапы, переходы, распределения и задачи. Ключ API хранится в существующем игнорируемом окружении.

По просьбе пользователя экономить токены новые генерации остановлены. Три созданных тестовых веб-диалога поставлены на `disabled`. Контрольный веб-канал Виктории выключен и отвязан от партнёрской воронки. Партнёрская воронка снова имеет исходный пустой список каналов и продолжает принимать заявки через адаптер сайта.

Две созданные только для прогона задачи, один временный тестовый этап и дополнительное тестовое правило удалены после сохранения результатов. Контрольная карточка Гаруна возвращена в «VLICO_TEST | Диалог Гаруна», очередь прежней выключенной задачи отмены синхронизирована и пуста. Все оставшиеся исходящие задачи Eva выключены. Оригинальные задачи и исходные пять воронок сохранены.

Проверка выполнялась через API. Инструмент встроенного браузера возвращал `Local browser access is unavailable for this chat`, хотя вкладка у пользователя открыта. Повторная проверка документации восстановления дала тот же результат.

## Оставшаяся приёмка

1. Проверить штатную отправку реплики человеком из интерфейса Eva, принятие разговора и переключатель остановки ИИ. Повторить входящее сообщение в этом же разговоре после передачи.
2. Подключить канал уведомлений Владлена с его участием и подтвердить фактическое получение ссылки на контрольную карточку. Привязка его Telegram используется также для двухфакторного входа.
3. Разобрать задержки или отсутствие автоматических переходов и заполнения полей. Ручной перевод контрольной карточки не считать доказательством автоматизации.
4. Подтвердить отмену запланированного касания после обычного ответа и после запрета. Отдельно проверить обработку ответа, который сохраняет этап расчёта. Для партнёров проверить интерес, отказ и отмену цепочки.
5. До нового включения задач определить причину отсутствия контакта в очереди веб-канала. Результат Telegram не подтверждает работоспособность других каналов.

Источники контракта — [документация Eva API](https://eva.bz/support/api), ранее сохранённая копия документации и повторное чтение реальных записей API. Предыдущие ограничения описаны в [проверке M6](WIDGET-M6-2026-11-14.md) и [отчёте по касаниям](TOUCHES-AND-CHANNELS.md).

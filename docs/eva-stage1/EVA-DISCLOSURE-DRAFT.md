# Eva.bz в документах сайта — черновик для согласования

Уведомление рядом с полем ввода чата:

> Вы общаетесь с ИИ-консультантом VLICO. Сообщения передаются в Eva.bz для ответа и обработки обращения специалистами VLICO. Для консультации оставлять телефон или адрес необязательно. Подробнее — в политике обработки данных.

Абзац для политики о действующем виджете:

> Чат на сайте работает через Eva.bz. Сервис обрабатывает сообщения и указанные в них сведения, а также технические идентификаторы, необходимые для работы чата. Переписка и карточка обращения доступны уполномоченным сотрудникам VLICO, чтобы ответить на вопрос, подготовить расчёт или согласовать замер. Если вы оставили контакт для ответа, VLICO использует его для обработки вашего обращения.

Абзац для согласия на обычные формы, если будет включена доставка в Eva:

> Для обработки заявки VLICO может передать в Eva.bz имя, указанный способ связи, содержание обращения, параметры расчёта и сведения об источнике заявки, если они были получены. Заявка также сохраняется в закрытом кабинете сайта.

Перед публикацией владелец сверяет сведения о поставщике, договорные условия обработки, сроки хранения и порядок удаления в обоих кабинетах. Для обычных форм обновление текста согласия и политики следует выпускать до включения передачи. Текст для виджета рассматривается отдельно, поскольку чат уже работает.
